# 用无正文准入判断减少摘要请求输入

状态：接受（2026-10-01 确认）。

摘要候选命中长度范围后，可先用不含工具正文的固定前缀请求内部摘要准入适配器，只接受严格 `yes`/`no`；`yes` 才发起带正文的摘要请求，`no` 透传，判断失败或输出非法则直接发起带正文的摘要请求。准入判断默认关闭。前缀缓存命中只作为观测的性能优化，不是正确性前提；两次请求在语义上必须各自独立成立。隐私模式开启时跳过准入判断，直接执行一次同时返回隐私结论与摘要字段的请求。

更早的调研曾以「append 时刻不知道剩余请求数、默认缩减在 97% 情况下正确」为由否决这类判断，但那条否决的前提是按“正文能否由工具不变量重取”分类；本判断问的是任务相关性，且请求体不含工具正文，故不适用。该选择控制摘要模型成本与延迟，三类辅助请求各自可以关闭推理，默认关闭推理。
